# 理財稿查核

依文章實際主張選擇對應項目。把足以改變選擇的條件寫給讀者。其餘計算細節放在來源或編輯附註。

| 內容 | 查核或補寫 |
| --- | --- |
| 現金流、緊急預備金、債務 | 用相同期間比較收支，說清稅前或實領、固定或一次性、必要或可調整。只把可即時動用的錢計入相應估算。若談償還債務，核對利率定義、費用與提前清償條件。 |
| 投資、退休、長期試算 | 列出期間、幣別、起始金額與提領或投入的時間。區分名目與實質、年化與累計、稅費前與稅費後。依題目測一個會改變判斷的不利情境，例如市場下跌、通膨、收入中斷或提領早期虧損。 |
| 保險與房貸 | 以適用文件說明產品範圍及版本。保險視題目查保費、保障、除外或解約影響。房貸視題目查利率機制、還款期、費用及現金流壓力。 |
| 稅務、補助、退休制度 | 先確認地區、身分或資格、適用期間及門檻。用官方文件或主管機關資料查核。重要前提未知時，寫成有條件的說明或列出待補資料。 |
| 產品與選項比較 | 對齊期限、幣別、成本與風險。交代流動性、適用條件及資料日期。比較單一優點時，把可能翻轉選擇的代價寫進正文。 |
| 真實案例與個人化信件 | 確認可用範圍，刪除姓名、帳號、精確地點與可交叉辨認的細節。保留當事人已表達的目標，清楚標記已確認與待確認事項。去識別後仍可能被認出時，使用明示的假設情境。 |

## 查證與編輯處理

1. 對應最接近主張的一手來源。制度用主管機關或官方條文，產品用公開說明書或合約，統計用原始統計發布。對讀者有影響的主張，附來源及適用日或資料期間。
2. 重算稿中的重要數字，寫出足以復算的公式或口徑。使用簡化例子時寫明假設，例如「以收入中斷、每月必要支出維持 4 萬元且沒有額外支出計，12 萬元 ÷ 4 萬元／月，約可支應 3 個月」。
3. 如果風險、成本、贊助或佣金會影響讀者採信或比較，放在對應判斷附近。合作稿若缺報酬資料，於編輯附註標記待確認。
4. 發布稿保留已核實或能清楚限定的說法。若未核實項目是使用者要求的核心結果，交付可用的條件式草稿，並點出會影響結果的缺口。
