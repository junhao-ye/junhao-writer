# Substack 排版

為收件匣和手機上的閱讀安排段落。先讓讀者看懂這一期在談哪個選擇，再讓小標、列表與圖表幫他找回判斷線索。沿用使用者既有的欄目、署名與讀者設定。

## 文章與電子報

| 位置 | Junhao Writer 的預設寫法 |
| --- | --- |
| 標題欄 | 用一個具體處境、疑問或取捨破題。把讀者最需要辨認的詞放前面，例如退休、頭期款或醫療預備金。 |
| 副標欄 | 一句話補上對象、條件或讀完會知道的事。標題已提出的問題，副標就往前走一步。 |
| 開場 | 正文直接進入生活片刻。前幾段交代正在做的選擇，再決定是否需要背景資料。 |
| 正文 | 一段一件事，多數段落用一到三句。需要保留同一組條件或因果時可以寫長一些，讓篇章讀起來有自然長短。 |
| 小標 | 短隨筆可一路讀下去。長文在不同問題、情境或比較開始處，使用同一層級的編輯器原生小標。小標寫出具體問題或判斷，例如「如果照顧費要先付」。 |
| 重點與資料 | 粗體留給讀者需要回頭找的數字或條件。清單用於步驟和同口徑比較。表格在手機上難讀時，用同一組欄位逐案列出。使用圖表時，在正文或圖說附上主要結論、口徑與來源，並提供適當替代文字。 |
| 引述與分隔 | 引用使用引文區塊並交代來源。分隔線留給正文與固定欄目、附註或刊末之間的轉換。 |
| 結尾 | 先收束文章，回到開場或留下一個讀者可以帶回生活的問題。需要互動時，依讀者和發行目的選一個邀請，例如回信、留言、分享或訂閱。預設可省略。 |

試算前提、重大風險及足以改變判斷的利益揭露，放在對應主張附近。補充來源可放文末。若指定付費試讀，先讓公開段落完成一個具體的判斷，再在段落結束後標示付費分隔位置。公開段落中的數字或結論，須在讀者可見的範圍交代必要前提。

## 交付與預覽

- 依序交付標題欄、副標欄、正文三塊。正文使用可攜的 Markdown 表示段落、小標或引用，對應到編輯器的原生格式。標題與副標各貼入自己的欄位。
- 有必要才加一小段編輯備註，放在正文外，寫清要插入的原生按鈕、圖或付費分隔位置。需要訂閱按鈕時，用平台的原生按鈕，並按目標讀者的訂閱身分預覽。
- 若可預覽草稿，檢查手機畫面與電子郵件版，確認首屏、連結、圖表、段落及讀者權限呈現正確。電子郵件可能採用不同於網頁主題的字型與背景。沒有草稿預覽時，以單欄、短段和簡單區塊交付，需人工確認的地方只記在編輯備註。
- 明確指定 Notes 時，交付可獨立讀懂的一則短文。可用一個生活觀察帶出一個問題或判斷，有需要才加原文連結。

## 範例｜電子報

**標題欄**  
請假照顧家人，哪個月最吃緊？

**副標欄**  
用三筆數字，估算照顧期間的現金缺口。

**正文**

假設媽媽下個月出院，你把回診時間抄進行事曆。抄完才發現，前兩週有三個下午得請假。

如果那三個下午沒有薪水，這個月的收入就會少一筆。回診交通或臨時照顧的支出，也可能在這段時間增加。

### 把支出和領薪日排在一起

可以先列出那個月的三筆金額。

- 那個月原本的必要支出。
- 請假之後實際會收到的收入。
- 看診交通、餐食或臨時照顧新增的費用。

把必要支出加上新增費用，再扣掉實收收入。如果還有缺口，就看能用哪筆錢補，以及哪一天要付。有些家庭整季算起來付得出，最緊的卻是第一筆費用剛好落在薪水進帳前。

回到那張行事曆，你可以先圈出最早要付錢的那一天。再和家人談，那個星期誰能排班，哪些費用需要先準備。

**編輯備註示例**  
若希望讀者回信，在最後一段之後加一句「如果你也排過家人的照顧班表，哪一項費用是後來才想到的？」若這篇是付費文章並提供免費試讀，可在完成上面的缺口說明後插入付費分隔，再銜接逐月試算。

**常見修正**  
「照顧家人的財務準備」若同時出現在標題和副標，換成上例的一問一答。若原稿用了寬表格呈現三筆金額，保留同一口徑並換成短清單，讓收件匣裡的讀者也能讀完。

## 範例｜Notes

> 排家人的照顧班表時，也可以把下一次領薪的日子寫進去。
>
> 如果回診和交通費要先付，這個月最後算得過來，禮拜三也可能得先墊一筆。跟家人分工前，可以先問，誰那天有空，這筆錢又會從哪裡出？
