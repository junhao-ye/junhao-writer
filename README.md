# Junhao Writer

Junhao Writer 是一個繁體中文 Agent Skill，用於撰寫、潤稿與續寫理財和人生選擇的文章。從讀者的生活處境切入，說清楚目標、期限、現金流和取捨，讓讀者能自己判斷。

適用於理財專欄、電子報、客戶信與講稿。指定 Substack 時，文章會分開交付標題、副標與正文，也可依需求撰寫 Notes 短文。

## 安裝與使用

下載或複製此儲存庫，將整個 `junhao-writer` 資料夾放入支援 Agent Skills 的工具所使用的技能目錄。保留根目錄的 `SKILL.md` 和 `references/` 相對位置。

啟用技能後，可直接指定想要的稿型、讀者與素材。

> 用 Junhao Writer 把這份家庭照顧筆記寫成一篇 Substack 電子報。給第一次需要請假照顧家人的讀者，重點放在怎麼看出照顧費與領薪日之間的差距。
